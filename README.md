### 🔹 The Core Paradigm: Shifting from Probabilistic Drift to Deterministic Anchors
Modern coding agents frequently fail because they treat large repositories probabilistically, leading to catastrophic context drift and AI hallucinations. In mission-critical environments, this drift is completely unacceptable.

To achieve absolute truth in local code generation, our framework implements **The Law of the Diamond Workflow**—a rigid, multi-gated diagnostic protocol running entirely offline on consumer hardware:

1. **Gate 1: Identity & State Verification (`VANE_ROOT_STABLE_001`):** Establishes the foundational logical verification baseline, ensuring the model operates directly within authenticated system parameters.
2. **Gate 2: Domain-Specific Test Selection:** Isolates the repository diagnostic boundaries across Cloud, Network Topology, Application, and Hardware states, filtering out noise before the LLM window is engaged.
3. **Gate 3: Induced Subgraph RAG Execution:** Leverages the `swegemma` AST engine to crawl verified repository documentation, producing a 100% transparent, auditable evidence trail for the model's scratchpad.
4. **Gate 4: Actionable Insight & Patch Synthesis:** Converts localized structural telemetry into clean, syntactically non-drifted git patches verified by localized parsing rules.
